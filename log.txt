The frozen model is strongest on short inputs and loses to the on-line LSTM
past ~30 KB: it was trained on WRT-dictionary-encoded Wikipedia, so plain
ASCII prose is out of its training distribution, while the LSTM adapts to the
file at hand.  It still beats ppmd alone everywhere.

quantization, so running it in full precision is at worst neutral.  tools/
engine_cmp.cpp on a synthetic stream: mean |dp| 1.0e-03 per element, and the

The fp32 model is 5,897,145 parameters = 22.50 MB, contiguous.  engine_cmp
also checks the backup contract: copy the block, scale every weight by 1.03
(output moves by 0.12 L1), copy the block back, and the output is bit-identical
again.

multi-TU -Ofast build, so the tables above still stand.  Edge cases (empty,
1 byte, 20 KB of random, all 256 byte values) all round-trip.

Saving the final weights (5th argument), FX2TFWC2, the format they are read
from.  Rows keep the scale they were loaded with where it still covers them,
and an untrained embedding is written back verbatim, so a save with training
off is a byte-exact no-op; save(load(save(X))) == save(X) byte for byte, which
is what verifies the encoder against the decoder it mirrors.

"nul" (also NUL, nul:, /dev/null) as the weights_in argument starts from a
freshly initialized model rather than a file - the same thing a
TF_LOAD_WEIGHTS=0 build does, and byte-identical to it (book1000: 2047 both
ways).  The name is matched rather than opened: on Windows fopen("nul")
succeeds, so the loader would read an empty file and die.

Progress reporting.  The coding loop tests one mask per byte; the clock is read
on a stride that retunes itself to a fixed wall-clock spacing, so the cost does
not depend on the configuration:

  ppmd only, book1 (5.5 us/byte)   stride settles at 16384   53 clock reads total
  transformer frozen (7 ms/byte)   stride settles at 32      ~10 reads/second

Both give a half-second update cadence.  clock_gettime costs 27.5 ns here
(tsc clocksource), so the ppmd case spends about 1.5 us on timing across a
4.3 second run.  Best-of-9 interleaved runs, ppmd only on book1:
  PROGRESS=0  4.270s     PROGRESS=1  4.269s
The medians differ by 0.8% in both directions across repeats - that is machine
noise, the minima are identical.  Compressed output is byte-identical with and
without progress.
