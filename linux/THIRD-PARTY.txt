Third-party components of the Linux build of ROSE
==================================================

The C++ run-time library and Boost are linked statically into lib/librose.so
and the C++ run-time library into the programs in bin/; the files in
include/edg/ are copies of the system headers of the GCC, GNU C library and
Linux packages of the Ubuntu 24.04 system that the package was built on (the
front end parses with them; they are not compiled into the programs).
